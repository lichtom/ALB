Overview

ALB is a Lisp-dialect scripting language based on S-expressions. It features concise syntax, strong expressiveness, and support for functional programming and modular development.

λ

Lisp-Dialect

Clean S-expression syntax with macros, quasiquote, and pattern matching.

📦

Standard Libraries

Math, string, IO, GUI, and 2D game engine — all included out of the box.

🖥

Built-in IDE

Syntax highlighting, auto-complete, function hints, and one-click run.

⚡

Bytecode Compiler

Compile to bytecode (.albc), package with runtime into a standalone executable.

🎮

2D Game Engine

Agame library: window, graphics, input, image, text, and audio — zero dependencies on Windows.

🔌

C++ FFI

Extend with C++ libraries compiled on-the-fly with automatic caching.

Quick Start

; This is a comment (starts with ;)

; Print output
(print "Hello, ALB!")

; Define a variable
(let x 42)
(print x)

; Define a function
(let add (func (list a b) (+ a b)))
(print (add 3 5))   ; => 8

; Conditional
(if (> x 10)
  (print "big")
  (print "small"))

; Loop
(let i 0)
(while (< i 5)
  (print i)
  (set i (+ i 1)))

Special Forms

Variable Definition

; let — define a local variable
(let x 10)
(let name "ALB")

; set — modify an existing variable
(set x 20)

; const — define an immutable constant
(const MAX_SIZE 100)

; Compound assignment
(+= x 5)   ; x = x + 5
(-= x 3)   ; x = x - 3

Function Definition

; Standard func
(let add (func (list a b) (+ a b)))

; Arrow syntax
(let add (list a b) => (+ a b))

; Named func
(func add a b (+ a b))

; Keyword arguments (v0.1.0)
(let draw-rect (func (list x y :width 100 :height 50)
  (prints (str x " " y " " width " " height))))

; Variadic arguments
(let sum (func (list &rest args)
  (fold + args 0)))

Conditionals

; if — conditional branch
(if (> x 0)
  (print "positive")
  (print "non-positive"))

; when — execute only if true
(when (> score 90)
  (print "excellent"))

; match — pattern matching
(match value
  1 (print "one")
  2 (print "two")
  _ (print "other"))

; cond — multi-way conditional
(cond
  ((> score 90) "A")
  ((> score 80) "B")
  (else "F"))

Loops

; while — conditional loop
(let i 0)
(while (< i 10)
  (print i)
  (+= i 1))

; for-i — C-style indexed loop
(for-i (i 0 (< i 10) (+= i 1))
  (print i))

; do — sequential execution
(do
  (print "step 1")
  (print "step 2"))

Modules & Macros

; use — import modules
(use "math")
(use "string")
(use "math" :only (list pi sqrt abs))
(use "string" :as "s")

; defmacro — define a macro
(defmacro unless (cond body)
  `(if ,cond nil ,body))

; struct — define a struct type
(struct Point (x y))
(let p (Point 10 20))
(Point-x p)      ; => 10

agame — 2D Game Engine

(use "agame")

2D game engine with window management, graphics rendering, input handling, image loading, text rendering, and audio playback. Zero external dependencies on Windows (Win32 GDI backend).

(use "agame")

(agame-init "Moving Ball" 640 480)
(let x 320) (let y 240) (let speed 5)

(while (not (agame-should-quit))
  (agame-set-color (list 0 0 0 255))
  (agame-clear)
  (agame-set-color (list 255 100 100 255))
  (agame-fill-circle x y 20)
  (when (agame-key-pressed "left")  (set x (- x speed)))
  (when (agame-key-pressed "right") (set x (+ x speed)))
  (when (agame-key-pressed "up")    (set y (- y speed)))
  (when (agame-key-pressed "down")  (set y (+ y speed)))
  (agame-present)
  (agame-delay 16))

(agame-quit)

Compile & Distribute

Compile .alb scripts into standalone executables.

# Compile to bytecode
ALB.exe compile hello.alb                   # → hello.albc
ALB.exe compile hello.alb --obfuscate       # with XOR obfuscation

# Build standalone executable
ALB.exe -b script.alb -o script.exe         # normal (needs lib/)
ALB.exe -b script.alb --embed -o script.exe # fully standalone

# Package for distribution
ALB.exe package hello.alb                   # → hello.zip
ALB.exe package hello.alb -o myapp.zip      # custom name

# Run bytecode
ALB.exe hello.albc                          # auto-detect

Bytecode format (.albc): 28-byte header (magic ALBC, version, flags, checksum) + serialized AST. Optional XOR string obfuscation.

Distribution package: .albc + ALB.exe + run.bat + manifest.json

IDE Usage

ALB IDE is a lightweight editor built with Python + Tkinter:

  • Multi-tab editing with syntax highlighting
  • Auto-completion (Ctrl+Space)
  • Function signature hints (auto-shows after typing ()
  • Smart indentation (auto-aligns based on parenthesis depth)
  • Project management (.albprj files)
  • F5 — Run   F7 — Build Executable   F8 — Build with Libraries

Number Guessing Game

(let target (random-int 1 100))
(let attempts 0)
(print "Guess a number between 1 and 100!")

(while true
  (let guess (num (input "Your guess: ")))
  (+= attempts 1)
  (if (== guess target)
    (do
      (print (str "Congrats! You got it in " attempts " tries!"))
      (break))
    (if (< guess target)
      (print "Too low!")
      (print "Too high!"))))

  (print (str (nth parts 0) ": " (nth parts 1))))

Functional Programming

; Sum a list
(let nums (list 1 2 3 4 5))
(let total (fold + nums 0))    ; => 15

; Filter even numbers
(let evens (filter (func (list x) (== (% x 2) 0)) nums))

; Map squares
(let squares (map (func (list x) (* x x)) nums))
