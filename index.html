What is ALB?

ALB is a Lisp-dialect scripting language based on S-expressions. It combines clean, minimal syntax with strong expressiveness, supporting functional programming, macros, pattern matching, and modular development — all in a single lightweight interpreter.

Whether you are writing quick automation scripts, building GUI tools, or creating 2D games, ALB gives you a productive, batteries-included environment with a built-in IDE and a rich set of standard libraries.
